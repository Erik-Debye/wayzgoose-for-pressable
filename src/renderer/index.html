    Pressable keeps 3 of each type per site, so the oldest one is replaced when a site is full.

    Edge cache is the page cache served from Pressable’s edge network. Object cache is the Memcached layer behind WordPress; flushing it can slow a busy site briefly while it refills.

    Checks every plugin and theme against WPScan’s vulnerability data (the same data behind MyPressable’s Security Alerts), then looks each CVE up for its severity and the access an attacker needs. Pressable refreshes this data daily, so once a day is plenty.

    Cache preload crawls a site to warm its pages after each cache clear. It needs a live site with edge cache on, and turning edge cache off also turns preload off.
